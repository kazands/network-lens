# Store listing identity

- Launcher and in-app name: **Network Lens**
- Planned Google Play listing title: **Network Lens: Network Scanner**
- English title: `en-US/title.txt`

The listing title is separate from Android app_name. These files record the approved title for a future Google Play release; they do not publish or reserve a listing. Version 0.3.10 uses `io.github.kazands.networklens` as its Android application ID. It installs separately from earlier previews, while retaining the existing app-signing certificate. Future updates to this identity must keep that ID and certificate. See [the identity change](../docs/IDENTITY-MIGRATION.md).
