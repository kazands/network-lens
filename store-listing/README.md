# Store listing identity

- Launcher and in-app name: **Network Lens**
- Planned Google Play listing title: **Network Lens: Network Scanner**
- English title: `en-US/title.txt`

The listing title is separate from Android app_name. These files record the approved title for a future Google Play release; they do not publish or reserve a listing. Current previews use `io.github.kazands.networklens` as the Android application ID. Public APK updates retain that ID and the pinned public signing certificate. The current preview is distributed through GitHub, not Google Play. See [application identity and updates](../docs/APPLICATION-IDENTITY.md) and [release verification](../docs/VERIFICATION-0.3.25.md).
