# Security reporting

Network Lens is in development. There is no promise of exhaustive device discovery or vulnerability detection.

For a suspected vulnerability, use this repository's **Security → Report a vulnerability** form when available. If private reporting is unavailable, open a minimal issue asking for a private reporting channel. Do not publish exploit details, credentials, household inventories, SSIDs or device addresses in a public issue.

Describe the affected version, Android version, reproducible steps using synthetic or redacted inputs, expected behavior and actual impact. Test only networks and devices you are authorized to access.

Changes involving scope validation, untrusted packets/XML/HTTP, permissions, cancellation, identity association or data retention need focused security regression checks. Ordinary feature or device-recognition bugs can use public issues with private identifiers removed.
