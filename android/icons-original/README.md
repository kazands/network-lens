# Network Lens original icons

`remote.svg` is original Network Lens artwork, licensed GPL-3.0-only under the
repository LICENSE. It is not an upstream Lucide icon. Its 24-unit canvas,
2-unit strokes and rounded joins match the app's Lucide pictograms.

Regenerate the Android vector with `python3 scripts/convert-lucide-icons.py`.
The icon represents remote controls and remote-control hubs, not a specific
physical handset or the device's network connection type.
